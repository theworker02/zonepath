Zone CSV/TSV path tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/zonepath/

## Install / run

```bash
git clone https://github.com/theworker02/zonepath.git
cd zonepath
node src/cli.js
node --test
```
